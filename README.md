# Начало проекта "Личный дневник"
  
## Деплой проекта  
Проект планируется развернуть в YandexCloud
- Открывается по ссылке `http://localhost:8000/`

# Records (Записи)
## Что здесь есть?  
- Есть главная, список записей, создание и обновление, удаление записей. 
- Страницы будущей реализации возможных функций

### Главная
- На странице можно перейти на страницу входа или регистрации
- Ниже приветствие и будущие планы на сайт
- Также на этой странице можно будет связаться (бесполезно, конечно)

### Список записей
- Можно просматривать свои записи, на карточках есть дата, заголовок, содержание и настроение дня, также кнопки редактирования и удалении записи.
- Для просмотра деталей записи нудно нажать на карточку
- Есть функция поиска по заголовкам и содержанию
- Планируется фильтрация по дате, наличии медиафайлов и настроению
- Также планируется сортировка по дате (автоматически) и заголовку
- Можно перейти на страницу создания записка

### Создание и редактирование записи
- Можно поставить свою дату записи, настроение дня, написать заголовок и содержание
- Планируется реализация функции добавления картинки и музыки дня
- Новая запись появляется в дневнике
- После создания переходит на страницу детали записи

### Детали записи
- Здесь находится информация о созданной записи: дата и время создания, настроение, заголовок, содержание, дата обновления
- Также есть кнопки для перехода на страницу редактора и удалении записи

### Удаление записи
- Это предупреждение о последствиях удаления записи

# Users (Пользователя)
## Что здесь есть? 
- Страница входа, регистрации, профиля, редактирования и удаления.

### Вход
- Воспроизводится через почту и пароль
- Галочка "Запомнить меня" ничего не делает
- Можно перейти к регистрации

### Регистрация
- Здесь необходимо для регистрации указать почту и пароль, номер телефона по настроению
- В скором времени может реализоваться функция по контролю за хроническими заболеваниями, которая может дополнить страницу новыми данными
- также можно перейти на страницу входа

### Профиль
- Здесь указана информация о пользователе: почта, номер телефона, дата регистрации, активность (количество записей, идей и записи о здоровье)
- можно перейти на страницу редактирования или выйти из профиля

### Редактирование
- Можно поменять почту и телефон, пароль нельзя
- Можно удалить аккаунт

### Удаление
- Страница имеет информацию об последствиях, пароль и галочки согласия и причина удаления
- После всплывает окно об последствиях
- При согласии выводит еще одно окно, которое просит написать "УДАЛИТЬ" для подтверждения
- После аккаунт удаляется безвозвратно
