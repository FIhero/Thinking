# Начало проекта "Личный дневник"
  
## Деплой проекта  
Проект планируется развернуть в YandexCloud

# Records (Записи)
## Что здесь есть?  
- Появилась логика страниц в views для создания, редактирования, просмотра (как запись, так и список), удаления. 

# Users (Пользователя)
## Что здесь есть? 
- Появилась логика страниц в views для регистрации, входа, выхода из профиля, просмотр своего профиля, обновление и удаление.
